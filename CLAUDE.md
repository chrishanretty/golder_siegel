Replicating Golder, Golder and Siegel
===

Folder lit/ contains a PDF file with an academic article by Golder, Golder and Siegel. 

This article describes an agent based model of government formation.

The objective of this project is to replicate the model in R.

The replication code should as far as possible use parallelism gracefully.

The success of the project is measured by the match to the descriptive statistics in the article.

Steps include:

 - summarizing the ABM
 - writing R code to simulate a single run
 - write an R harness to run multiple simulations
 - Simulate the runs as in the paper
 - Evaluate match of descriptive statistics
 - Revise code accordingly
